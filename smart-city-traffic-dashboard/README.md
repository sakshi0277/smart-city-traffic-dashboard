# 🚦 Smart City Traffic & Route Intelligence Dashboard: Varanasi

5th-semester Data Science group mini project.

> **Honesty note:** No free, open live-traffic feed exists for Varanasi.
> Traffic congestion shown in this project is a **modelled estimate (SIMULATED)** and is
> **never** presented as live traffic.

## Data provenance labels
| Label | Meaning |
|---|---|
| 🟢 REAL | Downloaded from a genuine open source (OpenStreetMap, Open-Meteo, data.gov.in) |
| 🟡 SIMULATED | Generated by our code from stated assumptions |
| 🔵 DEMO | Hand-made sample records to demonstrate a feature |
| 🟣 USER | Submitted by a person through the dashboard |

## Features (planned)
Traffic congestion map, route comparison, closures and construction, public transport,
accident analysis, road condition, weather, ML congestion prediction, community reports,
light/dark theme, PDF report export.

## Quick start (Windows)
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python scripts/check_environment.py
streamlit run app/main.py
```
Having trouble with a DLL / Application Control error? See `docs/TROUBLESHOOTING_WINDOWS.md`.

## Run tests
```powershell
pytest
```
